# 주요 CWE 요약

> TrustChain AI 팀이 MITRE CWE 항목 정의를 바탕으로 작성한 한국어 요약입니다. 원문은 cwe.mitre.org 를 확인하세요.

## CWE-502 신뢰할 수 없는 데이터의 역직렬화
직렬화된 데이터를 검증 없이 객체로 복원하면 복원 과정에서 공격자가 지정한 코드가 실행될 수 있습니다. 완화 방법은 신뢰할 수 없는 입력의 역직렬화 금지, 코드 실행이 없는 데이터 형식 사용, 서명·해시로 무결성 확인입니다.

## CWE-1357 신뢰할 수 없는 구성요소에 대한 의존
충분히 검증되지 않은 서드파티 구성요소에 의존하면 해당 구성요소의 취약점·악성 코드가 제품에 유입됩니다. 완화 방법은 구성요소 출처 검증, SBOM 관리, 유지관리 상태 모니터링입니다.

## CWE-494 무결성 검사 없는 코드 다운로드
원격에서 받은 코드를 출처와 무결성 확인 없이 실행하는 약점입니다. 완화 방법은 암호학적 서명·해시 검증과 전송 구간 암호화입니다.

## CWE-829 신뢰할 수 없는 제어 영역의 기능 포함
외부 제어 영역에 있는 스크립트·라이브러리를 포함해 실행하면 그 영역이 변조될 때 제품이 공격받습니다. 완화 방법은 버전·해시 고정과 신뢰 경계 명확화입니다.

## CWE-78 운영체제 명령어 삽입
외부 입력으로 운영체제 명령을 구성할 때 특수문자를 무력화하지 않아 공격자가 추가 명령을 실행할 수 있는 약점입니다.

## CWE-89 SQL 삽입
외부 입력이 SQL 문의 구조를 변경할 수 있는 약점입니다. 파라미터화된 쿼리가 1차 완화 방법입니다.
